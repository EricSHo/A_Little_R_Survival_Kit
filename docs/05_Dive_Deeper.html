5  Dive Deeper

So far, we have discussed the basics of R that are sufficient for most situations. In this chapter, we will discuss several practical operations that require a more detailed discussion. That includes how to create summary tables from published work, create a small data set in a data frame, load a data set of any size into RStudio, define your own function, and leverage the family of apply() functions.

Learning Objectives:

  • Recreate a summary table from published work.

  • Create a small data frame with data.

  • Load a data set into RStudio.

  • Define your own functions.

  • Harness the family of apply() functions.

You see the data summary tables as those in @fig-5-1, so you want to recreate and analyze them yourself. The table() or group_by() functions mentioned in the previous chapters cannot help in this situation, as they require the raw data, like iris, where the information of each sample is accessible.

Here you will create the two tables in R as shown in Figure 5.1. Let us begin with the first table, which is a contingency table with two rows and five columns. As all the values in the table are numeric, each row is represented by a numeric vector. Here, we will use the c() function to create it. See Section 1.2.3. But the vector designated for the first row here is slightly different because we want to specify the column names and the values together (a named vector); as a result, the columns in the resultant table will be named.

row1 <- c(heart_disease=0, formerly=808, never=1802, smoke=728, unknown=1496)
row2 <- c(1, 77, 90, 61, 48)

Note that the order of the values in the named vector row1 determines the order of the columns in the table. Ensure that the same order is maintained for subsequent rows.

When all the rows have been defined, they will be stacked up into a table using the rbind() function as shown below.

my_tab1 <- rbind(row1, row2)
my_tab1
     heart_disease formerly never smoke unknown
row1             0      808  1802   728    1496
row2             1       77    90    61      48

Note that names row1 and row2 on the left are the names of the rows (rownames), they do not constitute a column of the table. Hence, it is a 2x5 table as shown by the dimension function dim() below.

dim(my_tab1)
[1] 2 5

Now, you can plot the table Section 3.2.4.

barplot(my_tab1, main="Recreate a Table", beside=T,
        legend.text = c("No heart disease","heart disease"))

Or, perform a \(\chi^{2}\) test of independence.

chisq.test(my_tab1, correct=F)
Warning in chisq.test(my_tab1, correct = F): Chi-squared approximation may be
incorrect

    Pearson's Chi-squared test

data:  my_tab1
X-squared = 61.967, df = 4, p-value = 1.119e-12

The second table in Figure 5.1 is different from the first one as each row contains a mixture of character (daily tobacco onsumption ) and numeric values (controls and cases), making vectors unsuitable for this situation. R provides an object similar to vectors, ordered sequences, that is the list object. The main difference between a vector and a list is that the latter allows values to have different data types, i.e., heterogeneous. Below is an example to define rows as list objects:

A <- list(group="A", daily_toba="0-9", ncontrols=90, ncases=14)
B <- list("B", "10-19", 44, 13)
C <- list("C", "20-29", 25, 8)
D <- list("D", "30+", 8, 11)

Similarly, the row (A) defines the values and column names of the resultant table. Now, rows are stacked up together to form a 4x4 table.

my_tab2 <- rbind(A,B,C,D)
my_tab2
  group daily_toba ncontrols ncases
A "A"   "0-9"      90        14    
B "B"   "10-19"    44        13    
C "C"   "20-29"    25        8     
D "D"   "30+"      8         11    
print(dim(my_tab2))
[1] 4 4

5.2 Create a small data frame with data in R

Here we will discuss two approaches to store a small data set in a data.frame object. If the data set is large, my recommendation is to store the data in a spreadsheet, e.g., Google Sheets or Microsoft Excel, and then upload it into RStudio. See the next section for more details.

5.2.1 Use data.frame() Function

Here is the first approach to create a data frame that takes two steps. The first step is to define each column (variable) as a vector, and then use the data.frame() function to combine them into a data frame. Here is an example to create a data frame with two columns: group, and systolic blood pressure (sbp), and eight rows. Two vectors, each with eight values, are created below:

group_data <- c("A","A","A","A","A","B","B","B")
sbp_data <- c(120,135,133,128,130,150,160,158)

Next, use the data.frame() function to combine the vectors into a data frame.

small_df1 <- data.frame(group = group_data,
                       sbp = sbp_data)
small_df1
  group sbp
1     A 120
2     A 135
3     A 133
4     A 128
5     A 130
6     B 150
7     B 160
8     B 158

5.2.2 Use read.table() Function

The second approach is to type out the values in columns as in the example below, and feed it to the read.table() function through the text= parameter.

content = ("
group sbp
A 120
A 135
A 133
A 128
A 130
B 150
B 160
B 158
")

small_df2 <- read.table(text = content, header = TRUE)
small_df2
  group sbp
1     A 120
2     A 135
3     A 133
4     A 128
5     A 130
6     B 150
7     B 160
8     B 158

There is no good or bad of either approach unless you want to use some R functions to generate the column vectors. In such a case, the first approach using data.frame() function is more trackable.

5.3 Load Data Sets into RStudio

Data sets are usually too large to be typed using the methods discussed in the previous section. Here, you will learn several ways to load a data set stored in a file into RStudio. The two common data file formats are: comma-separated (.csv) or tab-separated (.txt or .tsv). In a .csv file, the comma (,) serves as a column separator, separating data in one column from the other column, as shown in panel A of Figure 5.2. The other common separator is the tab value, which is usually invisible but is deliberately made visible in panel B.

5.3.1 read.csv() and read.table() Functions

R provides two functions to read the data file directly into RStudio. read.csv() reads a .csv file from the location provided. The location can be a URL or a file path to a file on your computer. For example, load the flight delays file from here: https://www.openintro.org/data/csv/airline_delay.csv. The first parameter is the file location. Make sure that it is in quotes.

5.4 Define Functions

When no built-in functions do what you want, it is the occasion to write your own functions. A function consists of input, process, and output. A daily analogy is the vending machine. The inputs are money and choice; the process is the mechanical system to fetch the selected beverage, snack, etc., and the output is the dispensed item.

Here are the four components required to define a function: a function name, argument(s), the body, and the output(s).

  • Function name: same as the rules in defining variables.

  • Argument(s): A function may have zero, 1, 2+ arguments or inputs.

  • Body: R code that takes the input argument(s), if any, performs the task, and returns the output.

  • Output(s): the value(s), object(s), or none returned to the caller.

Suppose we want to convert temperature from Fahrenheit to Celsius, \(C=\frac{5}{9} \times (F-32)\), with specified precision; the default is zero. Here is the function definition:

F2C <- function(f, decimals = 0) {
  return(round((f-32)*5/9, decimals))
}

The function name is F2C. The function takes two arguments: f that denotes the temperature in Fahrenheit, and the number of decimals, with the default zero. Note that arguments are not required to have default values. The body consists of one line of code: return(round((f-32)*5/9, decimals)). The output is the result of the arithmetic expression.

Let’s test it out.

temp1 <- F2C(100)
print(paste("100 F is equivalent to",temp1, "celsius"))
[1] "100 F is equivalent to 38 celsius"
temp2 <- F2C(-10, decimals = 2)
print(paste("-10 F is equivalent to",temp2, "celsius"))
[1] "-10 F is equivalent to -23.33 celsius"

5.5 The Apply-Like Family

The apply() family has seven members. Here we will focus on three members that will do 80% of the job: apply(), sapply(), and lappy().

5.5.1 Mechanic of Apply-Like Functions

Generally, apply-like functions execute a function over every value of an R composite object Section 1.2.2. While apply() evaluates along the rows or columns of 2D objects like matrices and data frames, functions like lapply() or sapply() iterate over elements in 1D objects like vectors and lists. The function that acts on each value of the targeted object can be an R built-in function or a user-defined function. More details about the apply-like functions will be discussed below.

5.5.2 lappy()

A note about the syntax. toupper() is a built-in function that changes the input text to uppercase. When we provide the function to any apply-like functions, specify the function’s name; do not include the parenthesis ( ).

Let’s look at another example of how to pass an argument to the function. The built-in data precip recorded the average amount of annual precipitation (in inches) for 70 US cities. Suppose we want to convert inches to centimeters (cm) with precision provided by the caller; the default is zero.

Let’s define a customized function for the conversion.

inch2cm <- function(inches, decimals = 0) {
  cm <- round(inches * 2.54, decimals)
  return(cm)
}

Next, convert all values in precip to cm using lapply(). In this call, the conversion is rounded up to the nearest whole number.

precip_cm <- lapply(precip, FUN=inch2cm)
print(precip_cm[1:3])
$Mobile
[1] 170

$Juneau
[1] 139

$Phoenix
[1] 18

You may notice the output looks strange, despite the conversion being correct. Please hold on to the question until the next section.

Pass an additional argument, decimals=2, to inch2cm in the lapply() function.

precip_cm <- lapply(precip, FUN=inch2cm, 2)
print(precip_cm[1:3])
$Mobile
[1] 170.18

$Juneau
[1] 138.94

$Phoenix
[1] 17.78

5.5.3 sapply()

The “s” of sapply() stands for simplified. It functions almost exactly like lapply() except that it returns a vector or matrix. Recall that lappy() always returns a list regardless of the input.

Here’s the same process to convert precipitation from inches to cm but using sapply().

precip_cm_vector <- sapply(precip, FUN = inch2cm, 2)
print(precip_cm_vector[1:3])
 Mobile  Juneau Phoenix 
 170.18  138.94   17.78

5.5.4 apply()

Here we will expand the apply operation on 2D objects like matrices or data frames using apply(). You can direct the function to all values in a row, a column, or both. The apply() function takes three arguments: a 1D or 2D object, margin, and function. Margin 1 means to apply the function row by row; 2 means column by column. If both are given, the function will process all values of the 2D object.

For example, calculate the column mean of the four numeric variables in iris.

apply(iris[,1:4], MARGIN = 2, FUN=mean)
Sepal.Length  Sepal.Width Petal.Length  Petal.Width 
    5.843333     3.057333     3.758000     1.199333

Convert all values from inches to cm in iris

iris_cm <- apply(iris[,1:4], MARGIN = c(1,2), FUN = inch2cm)
